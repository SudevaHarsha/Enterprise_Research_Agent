## 1. Method

The inventory below is generated from the **actual installed distributions** in
this environment (`importlib.metadata.distributions()`), classified against the
dependencies declared in `pyproject.toml`:

| Role | Meaning |
|---|---|
| **runtime** | Declared in `[project].dependencies` — required to run the application |
| **dev** | Declared in `[project.optional-dependencies].dev` — required to develop/test |
| **transitive** | Installed as a dependency of a runtime/dev package (not declared directly) |
| **project** | The ECRKE package itself (`ecrke`, editable install) |

License metadata is read from each distribution's metadata in this order:
`License-Expression` (PEP 639), the `License` field, then `License :: OSI Approved ::
...` classifiers; otherwise the cell reads `UNKNOWN` and must be verified from
the package's own metadata. Long license texts are truncated to 80 characters in
the table (full text lives in each package's metadata). The table format mirrors
`pip-licenses` (Name | Version | License) with a `Role` column appended.

## 5. LLM Provider Terms (service terms, not software licenses)

ECRKE calls hosted LLM APIs through the LiteLLM gateway (`app/services/llm_gateway.py`).
The model **software licenses** of the underlying frameworks are listed above; the
**API terms** that govern usage of hosted models are the providers' then-current
service terms, summarized one line each (per design/tech-stack docs — exact terms
live on the provider sites; keys are referenced by env-var NAME only, Rule 01):

| Provider | API terms (one-line summary) |
|---|---|
| **OpenAI** (default through `OPENAI_API_KEY` via LiteLLM) | Hosted API service; customer retains rights to outputs, subject to OpenAI's then-current API/service terms; no training on your API data by default per OpenAI's enterprise terms. |
| **Anthropic** (`ANTHROPIC_API_KEY` via LiteLLM) | Hosted API service; customer owns outputs, subject to Anthropic's then-current Commercial Terms; input/output not used to train models per default commercial terms. |
| **Google** — Gemini (`GEMINI_API_KEY` via LiteLLM) | Hosted API service via Google AI Studio / Vertex AI; subject to Google's then-current Generative AI API terms; usage governed by Google Cloud or AI Studio terms depending on endpoint. |
| **Local / Ollama** (optional `local` extra) | Self-hosted open-weight models; governed by each model's license (e.g. Gemma, Llama community licenses) — no external API terms. |

ECRKE is **provider-agnostic** (LiteLLM): adding or swapping a provider is
configuration, not code. No provider key value is ever stored in the repository
(see `.env.example` for the variable NAMES).
